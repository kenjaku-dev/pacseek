Features

Everything you reach for.
Nothing you don't.

Built on ratatui, tokio and libalpm, so it feels native to your terminal and stays out of the way.

One search, both worlds

Official repos via the local libalpm sync DB and the AUR via RPC v5, queried in parallel with tokio. Repo results come first, AUR after. Falls back to pacman -Ss when needed.

$ pacseek firefox extra/firefox 131.0-1 [installed] aur/firefox-bin 131.0-1 (+1200 5.2)

A real TUI

Tabs, a virtualized list, info and help popups, and a cached layout. Runs in an alternate screen and restores your terminal cleanly, even after a panic.

Install on Enter

Repo packages go through sudo pacman -S. AUR packages go through git clone + makepkg -si, with a PKGBUILD preview and namcap if it's installed.

Remover mode

Hit Tab to list installed packages and type to filter. You get a pacman -Qi preview before sudo pacman -Rs runs.

Script-friendly

Use --json, --no-tui or --no-color, and NO_COLOR is respected. --remove and --refresh work as one-shots, and PACSEEK_NOCONFIRM=1 skips the prompts.

TOML config

Change colors, borders, layout and timeouts in config.toml without recompiling. Drop a ./pacseek.toml in a folder for project-local settings.

Safe by default

Sources are fetched over HTTPS only. makepkg refuses to run as root (checked via nix::geteuid), the PKGBUILD is always shown, and a color_eyre panic hook is installed before the TUI starts so a crash never leaves your shell broken.

How it works

From keystroke to installed

01

Type

Your query is debounced and sent as you type: substring by default, --regex if you want it.

02

Query in parallel

libalpm sync DBs and the AUR RPC v5 are queried at the same time on tokio.

03

Merge & rank

Results are merged into one list, repos first, with installed, out-of-date, votes and popularity flags.

04

Enter

Confirm, and pacman -S or makepkg -si runs. You're back in the list right after.

Two modes, one Tab

Find it. Install it. Remove it.

🔍 Search · install

Search mode

Every package in core, extra, multilib and the AUR, behind one search bar.

  • Color-coded sources: core extra multilib aur
  • AUR votes and popularity inline, like (+1200 5.2)
  • i opens an info popup with version, URL, maintainer and status
  • Enter → confirm → install, then straight back to the list
🗑 Installed · remove

Remover mode

Clean up your system without remembering exact package names.

  • An empty filter lists every installed package; type to narrow it down
  • Enter / d / x → confirm popup with a pacman -Qi preview
  • Runs sudo pacman -Rs, so orphaned deps go too
  • pacseek --remove <pkg> does the same from scripts

CLI

Prefer one-shots? Skip the TUI.

Run pacseek <query> for plain output you can pipe, filter and script. With no args on a TTY, the TUI opens.

bash
$ pacseek firefox --limit 5
extra/firefox 131.0-1 [installed]
    Fast, Private & Safe Web Browser
extra/firefox-developer-edition 132.0b5-1
    Firefox for developers
aur/firefox-bin 131.0-1 (+1200 5.20)
    Standalone web browser from mozilla.org
aur/firefox-nightly-bin 133.0a1-1 (+412 1.90)
    Nightly build of Firefox

# no args on a TTY → TUI
$ pacseek
$ pacseek --tui
bash
$ pacseek neovim --json --limit 1 | jq '.[0]'

bash
# AUR only, match by name
$ pacseek yay --source aur --by name --limit 5

# regex (libalpm regex for repo, client-side for AUR)
$ pacseek "linux.*headers" --regex

# only what's already installed
$ pacseek rust --installed-only

# AUR first, no colors, no TUI (great for pipes)
$ pacseek python --bottom-up --no-color --no-tui

# --source  aur | repo | all     --by  name | name-desc | maintainer …
bash
# remove a package (asks to confirm on a TTY)
$ pacseek --remove htop

# unattended: skip remove / makepkg / refresh prompts
$ PACSEEK_NOCONFIRM=1 pacseek --remove htop

# refresh sync databases (sudo pacman -Sy)
$ pacseek --refresh
Config

Make it yours.
No recompile.

Every field is optional, and changes apply the next time you launch. Generate a starter file, then tweak away.

  • pacseek --init-config writes an example to ~/.config/pacseek/config.toml
  • --show-config prints the active path, and --config PATH overrides it
  • A ./pacseek.toml in the current folder overrides the global config
  • Themes, borders, popup sizes, debounce, timeouts, remove flags
~/.config/pacseek/config.toml
[search]
limit        = 50
source       = "all"        # aur | repo | all
by           = "name-desc"
timeout_secs = 15

[tui]
border           = "rounded"
highlight_symbol = "▸ "
debounce_ms      = 400

[theme]
border_focused = "cyan"
repo_core      = "red bold"
repo_extra     = "green bold"
repo_aur       = "magenta bold"
tab_selected   = "black on cyan bold"

[behavior]
remove_flags      = "Rs"
makepkg_noconfirm = false
Install

Up and running
in under a minute.

install.sh checks dependencies, builds a release binary and installs it to /usr/local/bin. Use --user to skip sudo.

pacman 5.1+ (libalpm 16) pacman-contrib git base-devel rust 1.88+
bash
$ git clone https://github.com/kenjaku-dev/pacseek
$ cd pacseek
$ ./install.sh            # deps + release build + /usr/local/bin
$ ./install.sh --help     # --prefix / --yes / --no-sync
bash
$ git clone https://github.com/kenjaku-dev/pacseek
$ cd pacseek
$ ./install.sh --user     # → ~/.cargo/bin (make sure it's on PATH)
bash
$ git clone https://github.com/kenjaku-dev/pacseek
$ cd pacseek
$ cargo install --path . --force   # or: make install
bash
$ git clone https://github.com/kenjaku-dev/pacseek
$ cd pacseek
$ cargo build --release      # ~5.1M stripped
$ sudo install -Dm755 target/release/pacseek /usr/local/bin/pacseek
$ sudo pacman -Sy            # sync DB before first repo search
