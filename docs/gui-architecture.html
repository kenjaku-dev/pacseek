pakmap GUI Architecture

Tauri 2.12 shell over the pakmap core — phase AB (spike), one process, zero logic duplication

Zero-duplication core

  • • GUI = new shell over the same pakmap lib
  • • CLI/TUI code paths untouched by design
  • • 166 existing tests = frozen regression contract
  • • workspace member gui/src-tauri, CLI default-members unchanged

Staged streaming IPC

  • • per-backend events: Repo → Aur → Flatpak → Done
  • • same active_search generation guard as the TUI
  • • no join-all-before-paint: first leg renders immediately
  • • errors as {code, message, hint} — copy from CLI hints

Privilege model

  • • GUI process never elevated
  • • pacman ops via pkexec (polkit handles auth UI)
  • • flatpak ops stay user-scope (no escalation)
  • • ops cancellable between phases only — never mid-transaction
